# Archived Next.js prototype

This folder preserves the original Next.js/React wrapper, the browser-local marketplace implementation, its artwork and the earlier preparation scripts. The active application has migrated to Express, EJS and Supabase PostgreSQL.

The original project was a local interactive preview. Its accounts, conversations, reviews and transactions used demo/browser state. The current application does not import or serve this archived source. Reusable design assets are retained separately under the active `public/` directory.

The one-off conversion helpers in this archive describe the migration history. They are not current build commands. Use the root scripts and [current setup guide](../../migration/setup-and-status.md).
